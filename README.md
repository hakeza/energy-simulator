## GitHub Pages
Для фронтенда загрузить в GitHub только `index.html`, `style.css`, `app.js`.

## Backend
Backend нужно запускать на Render/Railway/VPS/другом Node.js хостинге. Переменные `.env`:
- `BOT_TOKEN` — токен бота
- `ADMIN_ID=8179254915`
- `WEBAPP_URL=https://hakeza.github.io/energy-simulator/`
- `BACKEND_PUBLIC_URL=https://ваш-backend-домен`
- `CRYPTO_PAY_TOKEN` — токен Crypto Pay
- `XR_TOKEN` — Bearer token xRocket Pay API
- `XR_BASE=https://pay.api.xrocket.exchange`

После деплоя backend укажи его URL во фронтенде перед публикацией:
```js
window.ENERGY_BACKEND_URL='https://ваш-backend-домен';
```
Самый простой вариант — вставить эту строку в `index.html` перед `app.js`.
