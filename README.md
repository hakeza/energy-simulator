# Energy Simulator — Telegram Mini App

Стартовая версия главного меню.

## Сейчас есть
- главное меню;
- полка 3×3 на 9 предметов;
- раздел «Игры»;
- игра Crash в тестовом режиме;
- нижняя навигация в стиле Telegram Mini App;
- адаптация под телефон.

## Запуск
Открой `index.html` через локальный сервер, например:

`python -m http.server 8080`

Для Telegram Mini App нужен HTTPS-хостинг и бот, у которого настроена кнопка Web App/Menu Button.
