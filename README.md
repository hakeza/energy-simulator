# Energy Simulator — v2

Обновлённая версия Telegram Mini App.

## Что изменено
- Нижняя навигация: Главное Меню / Игры / Задания / Профиль.
- Яркий салатовый стиль.
- Crash полностью удалён.
- Добавлен Upgrader с круговым индикатором, шансом, стрелкой и анимацией результата.
- В главном меню сохранена полка 3×3 на 9 ячеек.
- Добавлена тестовая внутриигровая энергия (не реальные деньги).

## Запуск
Открой `index.html` через HTTPS-хостинг, например GitHub Pages.
Для Telegram Menu Button используй URL GitHub Pages.
